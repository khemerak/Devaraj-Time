# Contributing

Thank you for helping improve Devaraj Time. Read README.md, docs/architecture.md and docs/limitations.md before proposing changes. Open an issue for a reproducible bug or a focused feature proposal; describe the expected behavior and the affected version without including employee records, location evidence, credentials or private logs.

Keep changes focused. Use the existing frontend formatter and tests, and run backend unit/integration checks relevant to the change according to the README. Use only fictional data in tests. Include migration and rollback considerations when changing persisted data.

Contributions are provided under this repository's MIT license. Third-party dependencies and copied code must preserve their license obligations. No response times or automatic acceptance are promised.
