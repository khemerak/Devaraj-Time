# Using Devaraj Time

Devaraj Time is open-source software under the MIT license. You can use, modify, self-host and redistribute it subject to the license notice requirements. Third-party dependencies retain their own licenses. The software is provided as-is; paid services are separate agreements, not a requirement for using the source.

## Self-host
Use the public repository and follow README.md for development and docs/deployment.md for production. You are responsible for your infrastructure, credentials, backups, updates, employee data and operating policies. Read docs/limitations.md before adoption. A local demo is not a reviewed production deployment.
